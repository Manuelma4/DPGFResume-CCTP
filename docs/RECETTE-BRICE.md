# Recette métier proposée

Interlocuteur de validation : Brice.

## Échantillon

Utiliser les CCTP du projet `25_189_BONDUELLE` lorsque le partage réseau est monté,
et comparer chaque lot à une lecture manuelle.

## Contrôles

- le nom et le code de chaque lot sont corrects ;
- l'ordre des sections suit le CCTP ;
- aucun poste majeur du CCTP ne manque ;
- aucun poste sans justification source n'est créé ;
- la page ou l'extrait Word permet de retrouver la prescription ;
- les unités proposées sont cohérentes ;
- les quantités absentes restent vides ;
- un objet manuel ajouté est conservé après réouverture ;
- une variante est visible mais exclue des sous-totaux de base ;
- les prix unitaires sont saisissables dans Excel ;
- les sous-totaux, prorata, TVA et TTC sont corrects ;
- l'historique sépare les utilisateurs ;
- le classeur reste lisible à l'impression.

## Décisions métier à formaliser

- profondeur maximale de la hiérarchie à conserver ;
- règles d'unité par famille de travaux ;
- traitement des postes « pour mémoire » ;
- traitement des options, PSE et variantes ;
- taux de prorata par projet ;
- niveau de confiance minimal avant export ;
- nomenclature de lot attendue par TCO.
